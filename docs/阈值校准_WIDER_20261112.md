# 阈值校准（R2-5 / R1-7）— WIDER 留出验证集，2026-11-12

## 1. 先给结论

1. 论文式(8)把分数定义在 **64 位总载荷** 上，但代码的分数是 **48 位认证 tag** 的匹配率：
   `s = 1 - d_H(tag)/48`。8 位人数、8 位编号是精确检查，不参与分数。
   这解释了为什么论文里的 `0.8125 = 1 - 9/48`、`0.6667 = 1 - 16/48` 都是 1/48 的整数倍，
   而 `0.6406` 不是（`0.6406×48 = 30.75`）。**式(8) 必须把 L 改成 B = L−16 = 48。**
2. 旧代码的 `calibrate()` 用“经验 FAR ≤ target，再取最小 FRR”。由于人数/编号的精确门控，
   错密钥几乎全部结构失败，经验 FAR 在所有阈值上都是 0，该规则必然退化到最低阈值
   （旧运行选出 `0.0208`，即 1/48，显然不可用）。本版改为 **解析 tag 界 + 显式预算**。
3. `0.6667` 在 WIDER 验证集上 **没有任何 FRR 收益，却多接受 14/450 个错密钥人脸**：
   - 真脸低分最高只到 `0.6458`，`[0.6667, 0.8125)` 区间内 **0 张真脸**；
   - 错密钥人脸恰好有 **14 张 = 0.6667 (32/48)**。
   因此 blind 与 set 统一为 `γ = 0.8125 (τ=9)`，`0.6667` 废除。
4. 最终只有两个阈值：
   - metadata-assisted：`γ = 1.0000 (τ=0)`，`P_fa = 3.55e-15`；
   - blind fallback 与 set-level：`γ = 0.8125 (τ=9)`，`P_fa = 7.61e-6`，
     集合级联合界 `N·P_fa ≤ 1.52e-4 (N≤20)`。

## 2. 验证集（源图互斥，不接触 test）

- 数据：`assets/wider`（WIDER FAMILY 多人脸子集），seed `20261110`。
- 清单：214 张源图 → 101 张登记成功 → 52 张“全覆盖 + ≥2 脸”可入评估。
- 划分：按 `source_id`/`group_id`/SHA256 互斥，20 张 validation / 32 张 test。
- 验证集样本（本报告只用 validation）：
  - 20 张源图；
  - genuine：40 张图（clean + JPEG95），**180 张合格人脸**；
  - negative：100 张错密钥图（5 keys × 20 sources），**450 张人脸**；
  - 另有 replace / seamless / collage 负例用于集合级 FAR。
- 清单文件：`runs/wider_threshold_rev2/calibration/validation_manifest.csv`。
- 注意：WIDER 只有内容哈希分组，**不是身份/拍摄组互斥**；这一点必须写进论文局限。

## 3. 选择规则

对每个决策单元：

```
tau* = max { tau : N_faces * P_fa(tau) <= budget }
P_fa(tau) = 2^-48 * sum_{i=0..tau} C(48, i)
gamma* = 1 - tau*/48
```

| 单元 | 统计单位 | N_faces | budget | tau* | gamma* | 单脸界 | 集合界 |
|---|---|---|---|---|---|---|---|
| auto（metadata） | 人脸 | 1 | 1e-14 | 0 | 1.0000 | 3.55e-15 | — |
| blind（fallback） | 人脸 | 1 | 1e-5 | 9 | 0.8125 | 7.61e-6 | — |
| set（co-photo） | 整图（最差脸） | 20 | 2e-4 | 9 | 0.8125 | 7.61e-6 | 1.52e-4 |

预算不是从测试表反推的，是三个决策单元的误接受代价：
元数据模式定位精确、最严点不损失可用性；blind 是降级通道，允许有限 tag 预算；
集合级是论文主断言，按 N≤20 做联合界分摊。

## 4. WIDER 验证集上的实测（关键数字）

人脸级（180 真脸 / 450 错密钥脸）：

| 单元 | γ | τ | FAR | FRR | AUC | 0 误接受的 95% 上界 |
|---|---|---|---|---|---|---|
| auto | 1.0000 | 0 | 0/450 = 0 | 5.00% | 0.965 | 0.66%（按 450 次试验独立） |
| blind | 0.8125 | 9 | 0/450 = 0 | 9.44% | 0.941 | 同上 |
| blind（旧） | 0.6667 | 16 | **14/450 = 3.11%** | 9.44% | — | — |

整图级（set 单元，40 真图 / 160 负图）：

| γ | τ | FAR | FRR |
|---|---|---|---|
| 0.8125 | 9 | 0/160 | 20.0% |

说明：
- FRR 包含结构失败/不可判定，因此高于纯 tag 错误率；集合级 FRR 是 N 张脸合取后的结果。
- 0/450 的 95% 上界按试验独立算是 0.66%，但只有 20 张独立源图，按源图算是 13.9%。
  **不能把 0/450 当成“FAR < 1e-3 已被证明”。** 解析界是设计目标，实测零误接受只是相容证据。
- τ=16 的实测 FAR（3.11%）高于独立位模型的 1.47%，说明该模型在低比特数/投票相关时偏乐观；
  论文必须把式(7)写成“参考界”，不能写成操作保证（R3-7.3 已要求）。

## 6. 还必须处理的论文冲突（不能靠改代码解决）

1. **表5 的 0.75 / 0.6406 / 0.7969 不是 48 位分数**（0.6406×48=30.75）。
   它们来自旧的 64 位/32 位协议，必须用返修版重跑并替换；否则与式(8) 的 B=48 直接矛盾。
   返修版 WIDER 例子里攻击后结构失败，分数是 0，不会出现 0.64–0.80 的渐变，需要换用
   COCO 两人脸案例或保留 header 的替换协议重做。
2. **表8 的 90% blind 接受率是 CelebA 单脸数据**（`paper_experiment_outputs/metadata_vs_blind`），
   不是 WIDER 多人脸。本报告 WIDER test clean 的 blind 接受率是 62.5%。
   两套数据不能混写；表8 若保留 CelebA，必须用同一 12/更多张图在 `γ=0.8125` 下重测接受率。
3. **0.6667 必须从表8删除**，改为 0.8125；由于真脸分数不在 `(0.6667, 0.8125)` 区间，
   接受率不会因为这次替换而下降（WIDER 上完全不变），FAR 反而从 3.11% 降到 0。
4. 论文式(7) 的 L 改为 B=L−16；`τ=0/9`，`γ=1.0000/0.8125`；不要再写 `τ=21/12` 或 `0.6667`。
