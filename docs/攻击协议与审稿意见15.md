本说明取代旧文档中“中心裁剪、移除3.5%面积、不恢复尺寸”和默认13×13模糊核的描述。旧 runs 和 verification 输出不修改，它们仍对应各自当时的协议。

## 已实现的协议

- JPEG(50)：OpenCV imencode('.jpg')，IMWRITE_JPEG_QUALITY=50，随后 imdecode；其余编码选项默认，不额外声称指定了色度采样或量化表。
- Crop(3.5%)：宽、高分别保留0.965，尺寸用int向下取整；随机x再随机y，范围包括两个端点；双线性插值恢复原尺寸。3.5%是各边长缩减比例；忽略取整，移除面积约6.88%。
- Gaussian Blur(2.0)：OpenCV GaussianBlur，5×5核，sigma_x=sigma_y=2.0，BORDER_REFLECT_101。
- Cropout(30%)：一个连续矩形，宽round(W sqrt(0.3))、高round(H sqrt(0.3))，左上角在有效整数坐标中均匀采样，全部颜色通道填127，尺寸不变。实际比例受整数取整影响。它不是随机像素Dropout，也不是裁剪后缩放。这是明确的新协议，不能追认旧Cropout结果。
- 额外resize：按int计算缩放尺寸，双线性插值缩放后再恢复原尺寸，与旧resize_img一致。默认scale列表补充0.9。
- 额外rotate：中心(w//2,h//2)，双线性插值，BORDER_REFLECT，与旧rotate_img一致。
- stretch、平台模拟及其他独立扩展攻击保持原有含义。
- 四种主攻击独立从同一含水印图出发，不叠加。Revision将攻击结果存为PNG，避免额外JPEG保存。旧脚本按源扩展名保存，若源名为JPEG，可能额外经过默认JPEG编码，必须检查原攻击图，不能承诺历史数值完全相同。

## 复现范围

已确认的旧攻击操作按像素匹配原OpenCV调用；随机裁剪支持random.Random以核对原Python随机序列。Revision正式trial流程仍用独立NumPy Generator并记录seed，可重复新试验，但不复刻原Python全局随机序列。默认旧面积参数removed_area会报错，避免把旧协议清单静默解释成新定义。

原项目不修改。历史表格的水印/检测模块、图像、随机状态、软件版本和保存格式也必须一致，才能复现历史数值；仅改攻击不能保证这一点。

旧版同名cropout只有被注释的random_crop(0.7)；dropout是像素独立置零；现有记录不足以判定原Cropout列实际使用哪种。保留旧数据备查，使用本次明确Cropout重新生成并替换对应实验结果，不将新协议用于解释来源未知的旧分数。也应更新图3/图4或其他采用该攻击的结果说明及曲线。

The main reported edits are JPEG(50), Cropout(30\%),
Crop(3.5\%), and Gaussian Blur(2.0).
\textcolor{blue}{Each edit is applied independently to the

JPEG(50) uses OpenCV's \texttt{imencode} and \texttt{imdecode},

The horizontal and vertical offsets are sampled uniformly
from valid integer positions, and the crop is resized back
to the original dimensions using bilinear interpolation

in each spatial dimension, not the removed area fraction;
ignoring integer rounding, the removed area is approximately 6.88\%.
Cropout(30\%) preserves the image dimensions and replaces
a single randomly positioned rectangle of width
$\operatorname{round}(W\sqrt{0.30})$ and height
$\operatorname{round}(H\sqrt{0.30})$ with the constant
value 127 in all color channels. Its top-left position is
sampled uniformly from all valid integer positions.
Gaussian Blur(2.0) uses OpenCV's \texttt{GaussianBlur}
with a $5\times5$ kernel, $\sigma_x=\sigma_y=2.0$,
